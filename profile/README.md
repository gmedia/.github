# GMEDIA Digital Solution

**Building open technology for real-world problems.**

**GMEDIA — PT Media Sarana Data** is an Indonesian technology company based in
Yogyakarta, working across connectivity, infrastructure, software, and applied
technology.

This GitHub organization is the public home of our engineering work: developer
platforms, infrastructure tooling, security projects, business systems, and the
experiments that come before them.

---

## What We Build

**Infrastructure & Developer Platforms** — Deployment tooling, runtime agents,
and platform work that shortens the distance between a Git repository and a
running application.

**Security Engineering** — Vulnerability assessment tooling and the security
practices that go with operating real systems.

**Products & Business Systems** — Software for concrete operational and business
problems, including resource planning and financial analysis.

**Applied Engineering** — Prototypes and research we keep in the open when the
work is more useful shared than shelved.

## Featured Projects

### Sakala

**From a Git repository to a running application.**

[Sakala](https://sakala.dev) is an open-source deployment project initiated by
the Sakala maintainers, with GMEDIA as founding sponsor and infrastructure
supporter. That support covers domains, infrastructure, and technical help — the
roadmap, documentation, issues, and contributions stay open.

It is aimed at people who should not have to hand-configure a VPS, a reverse
proxy, and TLS before they can ship: students, beginner developers, educators,
communities, and small teams.

Sakala is under active development, and maturity varies across components. Check
each repository's own documentation for current capabilities and deployment
guidance.

- [sakala-console](https://github.com/gmedia/sakala-console) — SvelteKit dashboard
- [sakala-api](https://github.com/gmedia/sakala-api) — Laravel control plane
- [sakala-agent](https://github.com/gmedia/sakala-agent) — Rust runtime executor
- [sakala-infra](https://github.com/gmedia/sakala-infra) — local runtime playground
- [sakala-landing](https://github.com/gmedia/sakala-landing) — site and public documentation

### Labuh

A lightweight PaaS written in Rust, built to deploy and manage containerized
applications from standard Docker Compose files, with automatic HTTPS through
Caddy and a Svelte dashboard. It targets both x86_64 servers and ARM64 edge
devices.

[gmedia/labuh](https://github.com/gmedia/labuh) · MIT

### VulnScanner

A web-based vulnerability scanner developed under the Sinexis brand. It runs IP,
domain, and mobile application analysis through asynchronous workers, with
scheduled scans and multi-user workspaces, built on FastAPI, React, PostgreSQL,
Redis, and Celery.

[gmedia/vuln-scanner](https://github.com/gmedia/vuln-scanner)

### Dokfin Advisor

An AI service that analyses the financial health of Indonesian small and medium
businesses, producing structured reports through a LangGraph pipeline with
deterministic scoring rather than model output alone.

[gmedia/dokfin-advisor](https://github.com/gmedia/dokfin-advisor) · MIT

### ERP

A business management platform that integrates core operations across
departments: financial records, assets, customers, suppliers, products,
employees, and organizational branches.

[gmedia/erp](https://github.com/gmedia/erp)

## How We Build

**Solve real problems.** Technology earns its place when it improves how people
work and build.

**Keep systems understandable.** Simple systems are easier to operate, debug,
secure, and hand over.

**Design for operations.** Failure modes, observability, deployment, and
maintenance are part of the design, not a later concern.

**Treat security as engineering.** Security is a property of how something is
built, not a checklist at the end.

**Automate repetition.** People should spend their time on decisions, not on
mechanical work.

**Learn by building.** An experiment is worth running when it leaves us
understanding something new.
